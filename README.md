# 🛡️ Nolex

**Защита от утечки чувствительных данных при работе с AI**

Nolex - это комплексное решение для защиты конфиденциальной информации при взаимодействии с AI-платформами (ChatGPT, Claude, DeepSeek и др.).

## 📁 Структура проекта

```
nolex/
├── extension/     # Chrome расширение
├── website/       # Веб-сайт проекта
└── app/          # Мобильное/десктоп приложение
```

### 🔌 Extension (Chrome Extension)

Chrome расширение для автоматического обнаружения и замены чувствительных данных в файлах перед загрузкой на AI-платформы.

**Возможности:**
- ✅ Автоматическое сканирование файлов перед загрузкой
- ✅ Обнаружение 25+ типов чувствительных данных
- ✅ Интерактивный диалог с предпросмотром
- ✅ Локальная обработка - данные не покидают ваш компьютер

📖 [Подробнее →](extension/README.md)
