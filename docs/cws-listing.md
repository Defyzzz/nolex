## Full Description

```
Nolex protects your sensitive data when working with AI platforms like ChatGPT, Claude, Gemini, Copilot, and others.

HOW IT WORKS
Nolex runs entirely in your browser. It scans text inputs, clipboard paste events, and file uploads for sensitive information — and warns you before the data gets sent to an AI service.

WHAT IT DETECTS
Built-in detection patterns cover:
  • Full names (first + last)
  • Phone numbers (international formats)
  • Email addresses
  • Passport and ID numbers
  • Credit card numbers
  • Bank account / IBAN numbers
  • Tax identification numbers (INN/SNILS)
  • Dates of birth
  • Physical addresses

You can also create your own custom regex patterns with the built-in editor.

SMART CONSTRUCTOR
Don't know regex? Use the Smart Constructor to build detection rules visually — pick a data type, choose format options, and Nolex generates the pattern for you.

KEY FEATURES
  • Real-time scanning of text inputs and paste events
  • File upload interception with content analysis
  • Built-in patterns for common personal data types
  • Custom regex rules with import/export support
  • Smart Constructor for building rules without coding
  • Works on any website — not just AI platforms
  • Toggle individual rules on/off

PRIVACY FIRST
  • 100% local — your data never leaves your browser
  • Zero telemetry, zero analytics, zero tracking
  • No accounts required, no sign-up
  • No network requests made by the extension
  • All settings stored locally via chrome.storage.local
  • Open source: https://github.com/Defyzzz/nolex

PERMISSIONS EXPLAINED
  • "Read and change all your data on all websites" — needed to inject the detection script on any page where you might interact with AI. Nolex only reads text inputs to scan for sensitive data. It does not modify page content or collect browsing data.

Nolex is free and open source. Protect your privacy — install Nolex.
```
